# Metro Memory

Многопользовательская браузерная игра на память карточек с реальным временем. Построена на Node.js, Express, Socket.IO и SQLite. Дизайн в стиле тёмного Metro UI.

---

## Описание игры

Metro Memory — это классическая игра «Найди пару», переработанная для онлайн-режима. На поле расположены 36 перевёрнутых карточек, за которыми скрыты 18 пар эмодзи. Игроки ходят по очереди, открывая по два карточки за раз: совпадение засчитывается как очко и оставляет карты открытыми, а несовпадение закрывает их обратно и передаёт ход. Побеждает тот, кто набрал больше очков к концу партии.

## Основные возможности

### Многопользовательская игра (PvP)
- Создание публичных и приватных комнат (приватные закрыты замком 🔒)
- Просмотр списка открытых комнат в лобби в реальном времени
- Поиск комнат по названию, автору или категории
- Виртуальная прокрутка при большом количестве комнат

### Режим зрителя
- Любой игрок может войти в идущую публичную партию как зритель
- Зритель видит всё поле в реальном времени, включая открытые карты и статистику ходов

### Игра против бота
- Три уровня сложности: Лёгкий / Средний / Сложный
- Бот имитирует память: на высоком уровне запоминает расположение карточек и делает точные ходы
- Защита от спама: нельзя одновременно создать много незавершённых партий с ботом

### Система комбо
Каждый раз, когда игрок находит пары подряд без пропусков, множитель очков растёт:

| Совпадений подряд | Множитель | Цвет попапа |
|:-:|:-:|:-:|
| 2 | ×1.5 | Синий |
| 3 | ×2 | Зелёный |
| 4 | ×2.5 | Оранжевый + анимация тряски |
| 5+ | ×3 | Золотой + свечение |

При каждом начислении очков рядом с панелью игрока появляется плавающий `+N`, а цифра счёта вспыхивает золотом.

### Система возврата в игру (Rejoin)
Если один из игроков потерял соединение в ходе PvP-партии:

- Комната остаётся живой **10 минут** — партия не сбрасывается
- Второй игрок видит оверлей «Ожидаем возврата...» и ждёт
- У отключившегося игрока комната появляется **вверху лобби** с зелёным значком «Ваша игра» и пульсирующей подсветкой
- Кнопка **«Вернуться в игру»** восстанавливает всё состояние поля и продолжает партию
- Кнопка **«Покинуть игру»** полностью закрывает комнату — у второго игрока тоже
- Пока у игрока есть незавершённая партия, создание новых игр и присоединение к чужим заблокировано; при попытке появляется уведомление с теми же двумя кнопками

### Таблица лидеров
- Глобальный и пофильтрованный (по категории) рейтинг
- Обновляется в реальном времени через WebSocket
- Рядом с именем текущего пользователя отображается его место в топе

### Профиль игрока
- Настройка аватара (эмодзи), email, темы и языка интерфейса
- История матчей: соперник, счёт, результат, дата
- Статистика побед / поражений / ничьих для PvP и отдельно для каждого уровня бота
- Любимые карточки: какие пары игрок открывал чаще всего

### Интернационализация
- Два языка: русский и английский
- Авто-определение по настройкам браузера
- Переключение через профиль (без перезагрузки страницы)

## Установка и запуск

### Требования

- Node.js 18 или новее
- npm

### Установка зависимостей

```bash
npm install
```

### Конфигурация

Создайте файл `.env` в корне проекта (или задайте переменные окружения напрямую):

```
PORT=3000
MEMORY_DB_TYPE=sqlite
SESSION_SECRET=замените_на_свой_секрет
```

Для MySQL дополнительно укажите `MYSQL_HOST`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DATABASE`.

Все доступные переменные описаны в `.env.sample`.

### Запуск

```bash
node server.js
```

Откройте `http://localhost:3000` в браузере.

Или настройте Nginx
/etc/nginx/nginx.conf
```    
        http {
        ....
        # Для Socket.IO — мягкий лимит: 20 запросов в секунду
        limit_req_zone $binary_remote_addr zone=socketio:10m rate=20r/s;

        # Для auth endpoints — жёсткий лимит: 10 запросов в минуту
        limit_req_zone $binary_remote_addr zone=auth:10m rate=10r/m;

        # Для обычного API — 30 запросов в секунду
        limit_req_zone $binary_remote_addr zone=api:10m rate=30r/s;
        ....
    }
```
И расположите metro-memory.conf в:
```
/etc/nginx/nginx.conf.d/ или etc/nginx/sites-enabled
```
```
nginx -t - проверить конфигурацию
nginx -s reload - перезапустить nginx для примененя конфигурации
```

## Правила игры

1. Зарегистрируйтесь или войдите.
2. Создайте комнату (выберите категорию карточек, при желании включите приватность) или присоединитесь к открытой.
3. Игроки ходят по очереди: каждый ход — открыть две карты.
   - **Совпадение** → карты остаются открытыми, ход продолжается, комбо-счётчик растёт.
   - **Несовпадение** → карты закрываются, ход переходит к сопернику, комбо сбрасывается.
4. Когда все 18 пар найдены, подсчитываются очки. Победитель тот, у кого их больше. При равенстве — ничья.
