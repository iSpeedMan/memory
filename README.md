# Metro Memory

Многопользовательская браузерная игра на память карточек с реальным временем. Построена на Node.js, Express, Socket.IO и SQLite. Дизайн в стиле тёмного Metro UI.

---

## Описание игры

Metro Memory — классическая игра «Найди пару» в онлайн-режиме. На поле расположены перевёрнутые карточки, за которыми скрыты пары эмодзи (или изображений). Игроки ходят по очереди, открывая по два карточки за раз: совпадение засчитывается как очко и оставляет карты открытыми, а несовпадение закрывает их и передаёт ход. Побеждает тот, кто набрал больше очков.

Поддерживаются поля 4×4, 6×6 и 8×8.

---

## Основные возможности

### Многопользовательская игра (PvP)
- Создание публичных и приватных комнат
- Список открытых комнат в лобби в реальном времени
- Поиск комнат по названию, автору или категории

### Режим зрителя
- Любой игрок может войти в идущую публичную партию как зритель в реальном времени

### Игра против бота
- Четыре уровня сложности: Лёгкий / Средний / Сложный / Грандмастер
- Бот запоминает расположение карточек на высоких уровнях
- Защита от спама: нельзя одновременно создавать много партий с ботом

### Локальная игра
- Режим игры на одном устройстве (без сервера): два игрока за одним экраном или одиночный режим

### Система подсказок
- В игре доступны power-up: «Открыть одну карту», «Открыть пару», «Пропустить ход»
- Ограниченное число использований за партию

### Система комбо
Каждый раз, когда игрок находит пары подряд, множитель очков растёт (базовые очки × множитель):

| Совпадений подряд | Множитель | Очков за пару |
|:-:|:-:|:-:|
| 1 | ×1 | 2 |
| 2 | ×1.5 | 3 |
| 3 | ×2 | 4 |
| 4 | ×2.5 | 5 |
| 5+ | ×3 | 6 |

### Система возврата в игру (Rejoin)
- Комната остаётся живой **10 минут** после отключения
- Отключившийся игрок может вернуться и продолжить партию

### Таблица лидеров
- Глобальный и по-категорийный рейтинг, обновляется через WebSocket
- Кэш 30 секунд (двухуровневый: L1 память + L2 Redis при наличии)

### Друзья и личные сообщения
- Система друзей: запросы, список, онлайн-статус
- Личные сообщения (DM) между игроками в реальном времени
- Приглашение друга в приватную комнату напрямую из лобби

### Профиль игрока
- Настройка аватара (эмодзи), email, темы и языка интерфейса
- История матчей, статистика побед/ничьих/поражений
- Любимые карточки: какие пары игрок открывал чаще всего

### Система достижений
- Достижения за игровые события (серия побед, комбо и т.д.)
- Toast-уведомления в момент разблокировки

### Безопасность
- CSRF-защита: токен на базе сессии, проверяется на всех POST/PUT/DELETE запросах
- Content Security Policy (через Helmet)
- Rate limiting на HTTP и WebSocket запросы
- Санитизация аватара с блокировкой управляющих unicode-символов
- Цензура чата с системой предупреждений и TTL-кэшем состояния

### Интернационализация
- Два языка: русский и английский
- Авто-определение по настройкам браузера

## Технический стек

| Уровень | Технология |
|---|---|
| Среда выполнения | Node.js 20+ |
| Веб-фреймворк | Express 4 |
| Реальное время | Socket.IO |
| База данных | SQLite (по умолчанию) или MySQL |
| Кэш (опционально) | Redis (сессии, API-кэш, leaderboard, чат) |
| Фронтенд | Vanilla JS + CSS, сборка через esbuild |
| Сессии | `express-session` + `connect-sqlite3` / `connect-redis` |
| Авторизация | bcrypt (хеширование паролей) |
| Логирование | pino + pino-pretty |
| Тесты | Jest + supertest |

## Установка и запуск

### Требования
- Node.js 20 или новее

### Установка зависимостей

```bash
npm install
```

### Конфигурация

Задайте переменные окружения (или создайте `.env`):

```env
PORT=5000
MEMORY_DB_TYPE=sqlite
SESSION_SECRET=замените_на_длинный_случайный_секрет
```

Для MySQL дополнительно: `MYSQL_HOST`, `MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_DATABASE`.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `NODE_ENV` | `development` | `production` включает secure cookies (требует HTTPS) |
| `MEMORY_DB_TYPE` | `sqlite` | Тип БД: `sqlite` или `mysql` |
| `SQLITE_FILENAME` | `database.sqlite` | Имя файла SQLite |
| `SESSION_SECRET` | случайный | Секрет сессий (задайте своё!) |
| `REDIS_URL` | — | URL Redis (опционально, см. REDIS.md) |
| `BASE_URL` | авто | Внешний URL (для email-ссылок) |
| `FIRST_ADMIN_USERNAME` | `admin` | Логин первого администратора |
| `FIRST_ADMIN_PASSWORD` | `admin123` | Пароль первого администратора |
| `MAIL_HOST` | — | SMTP-хост (для сброса пароля) |

### Запуск (режим разработки)

```bash
node server.js
```

Откройте `http://localhost:5000` в браузере. В режиме разработки файлы отдаются напрямую из `public/`.

### Продакшн-сборка

Собирает 22 JS-файла в один минифицированный бандл и минифицирует CSS:

```bash
npm run build
node server.js
```

После сборки приложение автоматически переключается на `dist/` (кэш-заголовки `immutable` для хэшированных файлов).

| | До сборки | После сборки |
|---|---|---|
| JS HTTP-запросов | 23 | 2 |
| JS размер | 217 KB | 172 KB |
| CSS размер | 67 KB | 48 KB |

### Nginx

Разместите `nginx-metro-memory.conf` в `/etc/nginx/sites-enabled/` или `/etc/nginx/conf.d/`.

В `/etc/nginx/nginx.conf` (блок `http`) добавьте зоны rate limiting:

```nginx
limit_req_zone $binary_remote_addr zone=socketio:10m rate=20r/s;
limit_req_zone $binary_remote_addr zone=auth:10m    rate=10r/m;
limit_req_zone $binary_remote_addr zone=api:10m     rate=30r/s;
```

Проверка и перезагрузка:
```bash
nginx -t
nginx -s reload
```

## Правила игры

1. Зарегистрируйтесь или войдите.
2. Создайте комнату (категория, размер поля, приватность) или присоединитесь к открытой.
3. Игроки ходят по очереди: каждый ход — открыть две карты.
   - **Совпадение** → карты остаются открытыми, ход продолжается, комбо растёт.
   - **Несовпадение** → карты закрываются, ход переходит к сопернику, комбо сбрасывается.
4. Когда все пары найдены, подсчитываются очки. При равенстве — ничья.
